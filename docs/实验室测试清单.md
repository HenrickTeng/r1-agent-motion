# 实验室子系统测试清单（近距迎宾 + 现有课堂功能）

给明天真机用。遥控器急停一直握在手里。每一项先看「通过标准」，再打勾。测近距迎宾时人站侧面或斜前方，不要正对挥手轨迹贴脸。

约定：

- 项目根目录：`r1-agent-motion`
- Python：`.venv-r1/bin/python`（不要用系统 3.13）
- 网页：`http://127.0.0.1:8765`
- 近距档位：**0.5–1.8 m 迎宾** · **0.3–0.5 m 提醒、不挥手** · **&lt;0.3 m 贴脸停手**
- 图传：教师台用 **video_hub** 的一张 img（1280×720）。2026-09-24 挡住左眼画面不变，这路是**右眼单独**在拍。左右眼小图是 UDP 5002/5003，要关 video_hub 才有，和教师台冲突。详见 `docs/教师控制台.md`「机载图像」。
- 近距测距：人体骨架（肩宽 / 躯干），来源应为 `pose-shoulder` 或 `pose-torso`。2026-09-24 实验室接受此方法，不靠双目深度图判 0.3/0.5 米。

## D. 近距迎宾（本轮新功能，真机）

选项卡 **近距迎宾** → **开始近距迎宾**。看页上「测距 / 区 / 来源」，以及机器人是否动手。全程不该出现走动。

建议用卷尺或地面胶带标 **0.3 m、0.5 m、1.0 m、2.0 m**（从胸口到机器人头部相机，不要从脚尖估）。

| # | 距离 | 人做什么 | 期望（区 / 动作 / 话） | 通过 | 实测距离与话 |
|---|---|---|---|---|---|
| D1 | &gt;2 m | 站着 | `far`，不挥手、不走路 | | |
| D2 | ~1.0 m | 走进迎宾带，先不特意做手势 | `greet`，挥右手并说「你好，很高兴见到你。」（约 8 s 内只一次） | | |
| D3 | ~1.0 m | 张开手掌或单臂侧举 | 再挥手（左手侧举应对挥左手）；仍不走 | | |
| D4 | ~1.0 m | 比耶或双手上举 | 欢呼 `cheer_both` | | |
| D5 | ~1.0 m | 握拳或双臂下垂 | 回准备姿态 | | |
| D6 | 0.3–0.5 m | 慢慢靠近 | `caution`，**不挥手**，TTS：「请稍微离我远一点，半米内挥手我担心不小心伤到你。」约 6 s 最多说一次 | | |
| D7 | &lt;0.3 m | 继续靠近（侧面，别贴挥手轨迹） | `danger`，停手；TTS：「太近了，请先退到半米以外。贴脸时我不会动手。」正在挥的手臂可能停在半道，属预期 | | |
| D8 | 退回 1 m | 离开后再走进来 | 可以再迎宾一次 | | |

失败时看网页「来源」：`stereo-empty` 是拼了左右目但框内没有效视差；`no-person` 是没检测到人；数字乱跳先看档位（绿迎宾 / 黄提醒 / 红停手）是否跟卷尺一致。

## 明天最可能碰到的情况

1. **机载仍是单路 JPEG**（当前 `GetImageSample` 常见如此）→ `source=bbox`，深度色块没有。仍应能按远近分档，数字不必精确到厘米。若 1 m 被当成贴脸或 0.4 m 仍挥手，记实测米数，回来改框高/焦距，不是先改动作库。
2. **真是左右拼图但深度花** → 人站亮处、别贴墙；仍以档位为准。
3. **迎宾挥手太勤** → 同一人在带内约 8 s 只自动迎一次；换手势才再做。若每秒都挥，记下来。
4. **TTS 把自己当指令** → 听一轮要等播完再说话；控制台已有冷却，仍尽量错开。

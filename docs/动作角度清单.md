# R1 动作列表与关节角度说明

> 来源：吴博版 `r1_agent/dds_robot.py` 的 MOTIONS 表。本文档是 `actions.json`（动作名/别名）的关节角度展开版，供「双手动作模仿/编辑」学生项目参考。角度单位均为弧度 rad。

## 关节顺序（JOINTS）

`JOINTS = (15, 16, 17, 18, 19, 22, 23, 24, 25, 26, 13, 29, 30)`

按顺序依次是：

- 左臂 J1~J5：肩俯仰 LSP(15)、肩横滚 LSR(16)、肩偏航 LSY(17)、肘 LE(18)、腕横滚 LWR(19)
- 右臂 J1~J5：肩俯仰 RSP(22)、肩横滚 RSR(23)、肩偏航 RSY(24)、肘 RE(25)、腕横滚 RWR(26)
- 腰偏航 WY(13)、头俯仰 HP(29)、头偏航 HY(30)

## 缩放规则（重要）

代码里存的不是直接角度，而是「系数值 × 缩放」：

- 肩俯仰（J1：LSP / RSP）**× 3.0**
- 其余所有关节 **× 1.8**

下面列的都是乘完后的实际弧度。

> 注意：所有动作都没有用到 J3 肩偏航（LSY / RSY）。上肢动作实际只用 J1 肩俯仰、J2 肩横滚、J4 肘、J5 腕。

## 关键提示

- 肩俯仰（J1）决定「手举多高」，范围约 -0.72（鼓掌）到 -1.56（伸懒腰）。若要调拥抱举更高，改 hug 段1 的肩俯仰值即可（当前 -1.50）。
- 肩横滚（J2）决定「手臂往外张」，张开双臂 ±0.684 是最大。
- 腕横滚（J5）是挥手/鼓掌这类动作的「摆手腕」来源。

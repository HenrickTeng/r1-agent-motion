# 动作库 / 技能 / Python 真机测试

给实验室勾选用。遥控器急停一直握在手里。人站在机器人侧面或斜前方，不要正对挥手轨迹。

这一页测的是教师控制台「动作库与技能」。数据格式对齐课程平台，执行仍走走跑 + `arm_sdk`。坐下、蹲下不会发给真机。

约定：

- 网页：`http://127.0.0.1:8765`
- 选项卡：**动作模仿**负责跟臂和记帧；**动作库与技能**负责保存、回放、技能包、Python
- 动作库文件：`programs/motion_library.json`
- 导出动作组：`r1-arm-imitate-mirror/v1`，`angle_convention` 为 `eduplatform-r1-mjcf/v1`
- 导出技能包：`eduplatform-skillpack/v3`

```bash
cd /path/to/r1-agent-motion
PYTHONPATH=. .venv-r1/bin/python -m r1_studio --hardware --interface auto
```

`--interface auto` 找不到网卡时改成实际网卡名。R1 先站稳走跑（FSM 811，上肢接管后可以是 816）。未站稳不要点「开始」。

离开本页或换选项卡会停掉当前后台。记帧时「动作模仿」要保持开启；回放和 Python 必须改点「开始技能」，两边不要同时开。

## B. 记一个动作组

顺序不要反：先跟臂，再记帧，最后换到技能页回放。

| # | 测什么 | 怎么做 | 通过 | 记录 |
|---|---|---|---|---|
| B1 | 跟臂 | 「动作模仿」→ 开始。人进画面，抬一侧手臂 | 机器人跟着抬。约定：人的右手 → 机器人左臂 | 跟的是左还是右： |
| B2 | 记两帧 | 保持模仿开着，切到「动作库与技能」，点两次「记录关键帧」。中间停大约 1 秒 | 列表出现 #1、#2。第 1 帧间隔是 0，第 2 帧大约 1 秒，可改 | 间隔秒数： |

## D. 技能流程

仍在「开始技能」之下。流程里放：招手 2 次 → 刚保存的动作组 1 次 → 等待 1 秒 → 前进 1 步。

| # | 测什么 | 怎么做 | 通过 | 记录 |
|---|---|---|---|---|
| D1 | 运行 | 点运行技能 | 先挥右手两次，再播动作组，停约 1 秒，再慢走一小步，然后停 | 顺序对不对： |
| D2 | 转向 | 单独一条「左转 90 度」 | 大约转四分之一圈，不横移 | 实际大概角度： |
| D3 | 导出 ZIP | 技能名称写「迎宾测试」，导出 | 压缩包里有 `skill.json`、`manifest.json`、`skill.py`、`README.txt`。用到的动作组在 `actions/<id>.json` | |
| D4 | 包内标记 | 打开 `manifest.json` | `hardware_authorized` 是 false，`model` 是 r1，`angle_convention` 与动作组一致 | |
| D5 | 删除动作组后再运行 | 流程里留着已删除的组，再运行 | 提示动作库里没有，机器人不开始做 | |

页面上的内置动作对应真机白名单：前进/后退是慢走，招手是挥右手，举手、抱拳是右手，抛手走欢呼。坐下和蹲下不在下拉框里。

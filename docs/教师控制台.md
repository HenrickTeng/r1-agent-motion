# 教师电脑本地课堂控制台

R1 **不接入** 教学平台。学生以后可以在网页上拼方块，导出 `.r1prog.json`；教师用网线连机器人，在这台控制台打开文件并运行。

视觉风格靠近课程平台（紫头栏、圆角卡片），但是跑在 `127.0.0.1`，只给教师电脑用。

## 分阶段测试（先单功能，再仿真编序列）

明天实验室按条勾选（网线、图传、近距档位、语音联动、对照原功能）：见 [实验室测试清单.md](实验室测试清单.md)。

不要一上来就开网页+真机。按这个顺序：

```bash
# 1) 只测手势：终端打印 JSON（poses / kind / vx / omega），不驱动机器人
PYTHONPATH=. .venv-r1/bin/python -m r1_studio --probe gestures --camera 0
# 要看画面再加 --window ；机载摄像头用 --r1-camera

# 2) 只测失物检测：每秒打印一帧类别
PYTHONPATH=. .venv-r1/bin/python -m r1_studio --probe vision --camera 0

# 3) 只测键盘映射：窗口内 WASD/QE，终端打印速度
PYTHONPATH=. .venv-r1/bin/python -m r1_studio --probe keys

# 测 DeepSeek Key（不打印密钥；须在同一终端 export 过真实 key）
PYTHONPATH=. .venv-r1/bin/python -m r1_studio --probe llm

# 4) 在原来的 MuJoCo 仿真里编辑课堂动作序列（挥手、欢呼、点头…）
PYTHONPATH=. .venv-r1/bin/python -m imitate --edit-sequence --full-model
# 直接预览一段：
PYTHONPATH=. .venv-r1/bin/python -m imitate --edit-sequence --full-model --play-sequence wave_right,cheer_both,nod
```

仿真编辑键：`[` `]` 换原子，空格加入序列，退格删除，`P` 播放，`C` 清空，`S` 保存成 `programs/custom_groups.json`（之后课堂网页「我的：xxx」方块能用）。无界面时加 `--no-mujoco` 只在终端走一遍。

## 启动完整控制台

```bash
# 真机、先不选摄像头：进 http://127.0.0.1:8765 再点笔记本或机载
PYTHONPATH=. .venv-r1/bin/python -m r1_studio --hardware

# 只看界面（不连真机、色块画面）
PYTHONPATH=. .venv-r1/bin/python -m r1_studio

# 启动时就打开电脑摄像头
PYTHONPATH=. .venv-r1/bin/python -m r1_studio --hardware --camera 0

# 启动时就打开 R1 头部图传
PYTHONPATH=. .venv-r1/bin/python -m r1_studio --hardware --r1-camera
```

浏览器打开 http://127.0.0.1:8765 。依赖：`.venv-r1/bin/pip install -e '.[studio,dev]'`（和 imitate 一样要 OpenCV + MediaPipe）。

笔记本摄像头预览按自拍镜像（画面左=你的左手），手势用手部关键点。R1 机载超广角不镜像、**不再中心裁切**，手势用跟臂同款 **MediaPipe Pose**（肩肘腕）。

选项卡和摄像头切换都只是预览：必须再点该功能的「开始」才会向 R1 发指令。「结束」只停新指令，已下发的无法撤回。换功能或换摄像头时若忘了关，会先停发并弹出安全提醒。

真机须走跑 **FSM 811** 或上肢接管后的 **816 ArmSdkLoco**，物理急停在手。松开键盘必须停步。软件软急停 = 停步 + 锁上肢，**不** Damp。拔网线停不了已经下发的步态，要用遥控器急停。

## 1. 手势操作

对齐大疆 Neo 的课堂语义（R1 没有高度轴）。**笔记本摄像头**仍用 MediaPipe Hands。**机载摄像头**太广、太糊，不抠掌心，改用跟臂同款全身 Pose：

- 机载先 **侧平举或双手上举** 锁定；双臂下垂停下；单臂侧举横移（你的左 = 机器人往你左边走）；侧平举后再分开后退、收拢前进；双手举过头顶保持约 0.4 秒欢呼。
- 笔记本：单手张开手掌左右横移；双手分开飞远、合拢飞近；食指转向；握拳停下；比耶欢呼。对照表在**右侧功能卡**，换机载摄像头会自动换成全身 Pose 列表。

首次会下载 Hands / Pose 模型（`r1_studio/assets/`、`imitate/assets/`，已 gitignore）。

## 2. 键盘遥控

点 **开始键盘遥控** 之后，请再 **点一下 QWEASD 格子**，让浏览器重新获得键盘；格子会亮。只点「开始」不点格子时，按键常被网页吃掉，看起来像要等很久或切走再切回来才有反应。不要点在课堂助手打字框里。点 **结束键盘遥控** 停止发新指令。空格停下。

| 键 | 动作 |
| --- | --- |
| W / ↑ | 前进 |
| S / ↓ | 后退 |
| A / D | 横移 |
| Q / ←、E / → | 左转 / 右转 |
| Space | 停下 |
| Shift | 半速 |
| 页面上的预设按钮 | 欢迎、上课、表扬、欢呼比耶等 |

速度上限和 `actions.json` 里的慢速移动同量级。

## 3. 校园识别对话

选项卡改为「校园识别」。先把公司 DeepSeek 的 Key、网关地址、模型名填进页面并保存（默认模型 `deepseek-flash`，即 V4.1 多模态）。密钥只留在本机进程里，不要写进仓库。

- 点 **开始校园识别**，对着镜头问「这是什么」「这本书该放在哪里」。
- 勾选 **加载示例图书馆平面** 后，按 `scenes/campus/library.txt` 指路（例如语文教材在三楼南区）。
- 不勾选时只有 `scenes/campus/context.txt` 的公共校园：不编楼层房间号，会先说物品类型，再建议失物招领/班级图书角等方向。
- 也可在文本框补充本校平面。对话会带上当前摄像头画面。

命令行仍可用环境变量：

```bash
export DEEPSEEK_API_KEY='公司给你的 key'
export DEEPSEEK_API_URL='https://api.deepseek.com'   # 或公司网关 /v1
export DEEPSEEK_MODEL='deepseek-flash'
```

没有 Key 时退回本地检测器的失物类别草稿。

## 4. 图形化编程（教师电脑版）

左边点方块，中间叠程序：移动、转向、上肢、说话、等待、系统组合、**自己命名的动作组**。

- **运行**：立刻在本机仿真或真机执行（白名单原子动作）
- **看 / 看命令 / 看整段命令**：弹出这一块（或整段）实际会发给 R1 的接口，例如 `SetVelocity`、`rt/arm_sdk`、语音 `TtsMaker`。只预览，不会动机器人
- **下载文件**：`*.r1prog.json`，以后学生网页作业交给教师用「打开」加载
- **录制自定义动作组**：程序里先排原子动作，起名后保存到 `programs/custom_groups.json`，工具箱出现「我的：xxx」方块

示例：`programs/examples/welcome.r1prog.json`

## 5. 语音问答 / 动作模仿 / 扳手腕（并进同一网页）

切功能时会把上一套后台**整段停掉**（卡顿可以接受）。

- **语音问答**：同一页里跑原来的 `r1-agent` 听一轮/打字规划。
- **近距迎宾**：用机载 img 上的人体骨架估距（见下节）。人在约 0.5–1.8 米时原地挥手问好；**不走路**。半米内语音提醒退后，0.3 米贴脸停手。课堂助手打字/听一轮会带上刚才的视觉迎宾上下文。

## 机载图像：video_hub 与左右眼

教师台 `--r1-camera` 走 `VideoClient.GetImageSample()`，服务名 **video_hub**。每次一张 JPEG，实验室实测 **1280×720**，对应手册里的 **img**。2026-09-24 现场：挡住头部**左眼**，这张画面完全不变，因此当前 video_hub 只用**右眼**在拍，不是左右合成，也不是左眼那路 544×448。

左右眼和官方深度是另一套，要在 App「设置 → 服务状态」打开 **Stereo patch PC1**，并关掉 **video_hub**（两套会冲突）。关了 video_hub 之后，教师台这条图传会断。

| 流 | 入口 | 分辨率 |
|---|---|---|
| img（教师台正在用） | video_hub，`GetImageSample` | 1280×720 |
| 左眼 RGB | UDP 5002 | 544×448 |
| 右眼 RGB | UDP 5003 | 544×448 |
| 官方深度 | Orin `/dev/video-dep`，数值÷1000 为米 | 544×448 |

服务开关接口是 `RobotStateClient.ServiceSwitch`（走 DDS 上的 RPC，和 App 同一套）。手册列出的可切换名字是 `ai_sport`、`basic_service`、`r1_arm_example`、`vui_service`、`unitree_slam`，**没有**写 `video_hub` / `stereo_patch_pc1`。受保护的服务会返回 5202。2026-09-24 实验室决定：迎宾继续用 video_hub 的 img，距离用骨架，不在上课时关 video_hub。

## 近距测距（骨架，2026-09-24 接受）

MediaPipe Pose 在 img 上取肩、髋。水平视场按约 120° 估焦距（手册模组水平 FOV 最大约 146°，未标定）。距离优先用肩宽约 0.38 m，其次肩到髋约 0.52 m；头到脚都看见时才用全身 1.65 m。操作台来源显示 `pose-shoulder` 或 `pose-torso`。这是档位用的方法，不是双目深度，也不是把半身框当成 1.65 m 全身。数字允许几十厘米误差。
- **动作模仿**：同一页里跑原来的 Pose 跟臂（人右手→机器人左臂）。须走跑，不要进调试。
- **扳手腕**：本页**不**替你进调试、也不发走跑步态。点「准备离开走跑」后，用遥控器进调试、跑原来单独能用的扳手腕程序。结束后必须 **R1 关机再开机**，回到本页点「已重新开机」，才能再开键盘/手势/跟臂。

## 安全

- 默认只监听 `127.0.0.1`，不要把控制台暴露到公网
- 禁止列表与问答 Demo 相同（跳舞、下蹲、奔跑等）
- 手势/键盘行走与语音原子相同：`SetVelocity(0.5, 0, 0, 0.5)`，返回 127 也算发出。松开或网页失联约 0.8s 会 `StopMove`。816（ArmSdkLoco）也可以走。
